# Credit Card Customer Churn Prediction

## Project Overview
This project focuses on predicting whether a credit card customer is likely to leave the bank using machine learning.

## Objectives
- Explore and understand customer data.
- Perform data preprocessing and categorical encoding.
- Scale numerical features using StandardScaler.
- Build a binary classification model.
- Evaluate the model's performance.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- TensorFlow / Keras
- Kaggle Notebook

## Workflow
1. Data loading and exploratory data analysis
2. Data preprocessing
3. Categorical encoding using one-hot encoding
4. Train-test split
5. Feature scaling
6. Neural network development
7. Model evaluation

## Dataset
The dataset was accessed through Kaggle. Refer to the original dataset source and its license before redistributing any data.
